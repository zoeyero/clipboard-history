clipboard历史剪切板
版本：0.4.1 · Windows x64

一、在另一台电脑上使用

1. 将 clipboard-0.4.1-win-x64.zip 复制到另一台电脑。
2. 右键压缩包，选择“全部解压”，放到你准备长期保留的文件夹。
3. 打开解压后的文件夹，双击 clipboard历史剪切板.exe。
   请先解压全部文件，不要直接在压缩包中运行。

运行环境：Windows 10 / 11 的 64 位系统，需要 .NET Framework 4.x，建议 4.8。
这是免安装的软件包，无须安装开发工具，也无须复制源码或测试文件。
不同电脑的显示缩放及其他软件的粘贴兼容性，仍需在目标电脑实际确认。

软件包包含：
- clipboard历史剪切板.exe：主程序。
- clipboard.ico：不带 N 标记的原版图标，可用于快捷方式。
- 使用说明.txt：本说明。
- User-Guide-English.txt：完整英文使用说明。
- SHA256.txt：以上文件的 SHA-256 校验值。

二、日常操作

复制文字或图片后，软件会自动记录。点击记录可发起粘贴；点击“预览”查看内容。
长文本预览自动换行，可上下滚动查看全文；复制的原始内容保持不变。
点击卡片右侧“···”或右键记录，可以收藏、置顶、编辑或删除。
顶部“历史”“收藏”“新建”“设置”用于切换记录和功能。
拖动记录正文或左侧手柄可调整顺序；搜索或类型筛选时不提供排序。
将鼠标放到窗口四边或四角，可以拖动调整窗口大小。

关闭主窗口只是收起，程序会继续记录剪贴板。
点击悬浮图标可以重新打开主窗口；双击系统托盘图标可找回悬浮图标。
需要完全退出时，请右键系统托盘图标，选择“退出软件”。

三、设置

打开“设置”，左侧选择分类，右侧修改具体内容：
- 常规：随 Windows 启动、粘贴后自动收起、字体大小和语言。
- 主题与背景：选择基础主题或图片自动取色，设置背景图片、裁剪选区、透明度和悬浮图标。
- 存储位置：查看数据目录或迁移到其他位置。
- 备份与恢复：导出或导入历史记录。
- 自动清理：按保留天数清理普通历史，置顶和收藏会保留。

“应用设置”会保存并生效，设置窗口保持打开。
“保存设置”会保存并关闭设置窗口。
直接关闭设置窗口会放弃尚未应用或保存的修改。

四、分享软件与迁移历史

本软件包不含个人历史记录、背景图片或个人设置，可以作为干净的软件包分享。
记录和设置默认保存在：
%LOCALAPPDATA%\ClipboardNext\Data
如果曾修改存储位置，请以“设置 → 存储位置”显示的目录为准。

如果还希望把历史记录转到另一台电脑：
1. 在原电脑打开“设置 → 备份与恢复 → 导出备份”，保存 .icb2 文件。
2. 将该备份文件复制到新电脑。
3. 在新电脑打开“设置 → 备份与恢复 → 导入备份”，选择 .icb2 文件。

备份包含文字、图片、备注、收藏、置顶、排序和使用时间。
导入会与现有记录合并；不会直接清空现有记录。
备份不含主题、背景、自定义图标、自启动和自动清理等设置，这些需在新电脑重新配置。
备份可能包含私人内容，仅在需要迁移记录时单独传递给可信接收方。

五、更新软件和任务栏图标

同一台电脑上的第二阶段版本共用原有数据位置；使用新软件包不会自动清空记录。
更新前可先导出一份备份，然后在托盘中退出旧程序，再启动新文件夹中的程序。
第一阶段程序及其独立数据目录不包含在本软件包中。


如果已经开启“随 Windows 启动”，移动程序文件夹后，请从新位置启动，
在“设置 → 常规”关闭并应用该选项，再重新开启并应用，以更新启动路径。

六、启动或更新遇到问题

- 程序已运行时，重复打开会显示原窗口，不会另外启动一份。
- 如果提示文件被占用，请先从托盘退出程序，再复制或更新文件。
- 如果系统提示缺少运行环境，请安装适用于当前 Windows 的 .NET Framework 4.8。
- 如果粘贴目标没有接收内容，可在目标软件中手动按 Ctrl+V。

七、只记录自己选中的内容（0.3.0）

打开“设置 → 记录与快捷键”，选“仅快捷键记录”，点击快捷键框，按下你想设置的组合键，再点“应用设置”。默认 Ctrl+Shift+C。

之后 Ctrl+C 或右键复制仅用于系统普通复制，不会进入本软件的历史。需要保留时，在目标软件选中内容，按下并松开专用快捷键；复制成功后会通知已加入历史。

也可设置 Ctrl+X。在仅快捷键模式下，它会复制并保存，不再剪切原文；关闭该模式或退出软件后恢复原有键盘行为。Ctrl+C 本身请通过“自动记录”模式使用。

未选中内容、复制失败、焦点切换或目标软件不支持复制时，不会保存旧剪贴板内容。普通权限程序无法保证对管理员权限窗口发起复制。

八、截图记录说明（0.3.1）

框选区域后，按下并松开记录快捷键，再立即点击截图工具的确定按钮。截图工具需将结果复制到系统剪贴板。当前需在 1.8 秒内确认，且截图窗口保持前台；不兼容的截图工具可使用自动记录模式。

设置中已删除快捷键推荐文案，默认组合可自行更改。

九、切换语言（0.4.1）

设置 → 常规 → 语言 / Language，选择简体中文或 English，点击应用设置或保存设置，即时生效并保存。切换只改变界面，记录原文、备注、背景及快捷键不变。Windows 文件选择器和系统异常详情遵循 Windows 系统语言。

English: Settings → General → Language → English → Apply or Save settings. Language changes immediately and is remembered on restart. Your records, notes, background and hotkey are preserved. Native Windows dialogs and system error details use the Windows language.
