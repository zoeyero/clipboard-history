Clipboard History
Version 0.4.0 · Windows x64

1. Getting started

Extract ALL files from clipboard-0.4.0-win-x64.zip into a permanent folder.
Run clipboard历史剪切板.exe from that folder, not from inside the ZIP.
Requires 64-bit Windows 10/11 and .NET Framework 4.x (4.8 recommended).
No installer or development tools are required. Display scaling and paste
compatibility should be checked on the destination PC.

Package contents:
- clipboard历史剪切板.exe: application
- clipboard.ico: original icon, without the N badge
- 使用说明.txt: Chinese user guide
- User-Guide-English.txt: English user guide
- SHA256.txt: checksums for the files above

2. Switch to English

The initial interface is Chinese. Open 设置 (Settings), then 常规 (General).
Find 语言 / Language, select English, and click 应用设置 (Apply) or
保存设置 (Save settings). The interface changes immediately and remembers
your choice after restart. You can switch back to 简体中文 at any time.
Records, notes, background and hotkey settings are preserved.
Native Windows file dialogs and system error details use the Windows language.

3. Everyday use

In automatic mode, copied text and images are added to history.
Click a record to paste it. Click View to preview the full content.
Long text wraps to the available width and scrolls vertically.
Right-click a record or click its three-dot menu to pin, favorite, edit or delete.
Use History, Favorites, New and Settings at the top of the window.
Drag the handle on the left to reorder within the same pinned or ordinary
section. Reordering is unavailable while searching or filtering by type.
Drag the window edges or corners to resize it.

Closing the main window hides it; the app continues running.
Click the floating bubble to reopen it. Double-click the tray icon to show
the bubble. To exit completely, right-click the tray icon and select Quit.

4. Settings

General: start with Windows, hide after pasting, font size and language.
Appearance: themes, colors from an image, background crop, opacity and bubble icon.
Storage: view or move the local data folder.
Backup / restore: export or import records.
Auto cleanup: permanently remove unused ordinary history after a chosen number
of days. Pinned and favorite records are kept.
Capture / hotkey: choose automatic or hotkey-only recording and set your hotkey.

Apply saves changes and keeps Settings open. Save settings saves and closes it.
Closing Settings without applying or saving discards pending changes.

5. Record only selected copies

Open Settings > Capture / hotkey and select Record only with a hotkey.
Click the hotkey field, press your chosen combination, then click Apply.
The default is Ctrl+Shift+C; it is customizable.

Ordinary Ctrl+C and right-click Copy still work through the system clipboard
but are not added to this app's history. To keep something, select it in the
target application, then press and release your capture hotkey.
The app reports when a new item has been added.

If you choose Ctrl+X, it copies and saves instead of cutting while hotkey-only
mode is enabled. Disable this mode or quit the app to release the combination.
For ordinary Ctrl+C capture, select automatic recording mode.

If copying fails, focus changes, or the target application does not support
Copy, old clipboard content is not saved. A normally launched app may not be
able to send Copy to an application running as administrator.

6. Screenshots

Select a region in your screenshot tool, press and release the capture hotkey,
then immediately confirm the screenshot. The tool must copy the result to the
system clipboard. Currently you must confirm within 1.8 seconds and keep the
screenshot window in front. Use automatic recording with incompatible tools.
Saving only an image file does not add it to clipboard history.

7. Share the app or move your history

This distribution contains no personal history, backgrounds or settings.
The default data folder is:
%LOCALAPPDATA%\IrisClipboardNext\Data
If you moved storage, use the path shown in Settings > Storage.

To move records to another PC:
1. On the original PC, open Settings > Backup / restore > Export backup.
2. Copy the resulting .icb2 file to the other PC.
3. On that PC, select Import backup and choose the file.

Backups include text, images, notes, favorites, pins, order and usage times.
Import merges records instead of clearing existing history.
Themes, backgrounds, custom icons, startup and cleanup settings are not part
of the backup; configure them again on the new PC.
Backups may contain private information. Share them separately only when needed.

8. Updates and shortcuts

Phase-two versions on the same PC reuse the existing data location.
Export a backup if desired, quit the old app from the tray, and start the new
executable. Phase-one software and its separate data folder are not included.

If the taskbar still shows the old N icon, unpin the old shortcut, quit the old
process, launch this version, and pin its taskbar icon again.
After moving the executable folder, disable Start with Windows and Apply,
then enable it and Apply again to refresh the startup path.

9. Troubleshooting

- Starting the app again brings up the existing instance.
- If an executable is in use, quit the app from the tray before replacing it.
- If the runtime is missing, install .NET Framework 4.8 for your Windows version.
- If the target did not receive a paste, press Ctrl+V in that application.
- If preview still scrolls horizontally, check the version in the Settings title.
  Quit older processes and start version 0.4.0 from this package.
